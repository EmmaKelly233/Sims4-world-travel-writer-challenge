# 世界旅行作家挑战｜The Wandering Writer

一个无需框架、无需安装依赖的中文单页网站，包含挑战规则、可点击旋转的随机转盘、世界人物任务、旅行清单和可保存/导出的旅行日志。

## 本地预览
直接用浏览器打开 `index.html`。

## 发布为 GitHub Pages 网址
1. 登录 GitHub，创建一个新仓库，例如 `wandering-writer-challenge`。
2. 上传 `index.html` 和 `README.md`。
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 **Save**。
6. 等待部署完成，GitHub 会显示网站网址，通常形如：
   `https://你的用户名.github.io/wandering-writer-challenge/`

## 功能说明
- 世界、地段类型、写作灵感、旅行事件、通用任务五个转盘。
- 转盘名单可编辑；世界转盘可选择优先抽取未探索世界。
- 可把抽中的世界标记为已探索。
- 旅行日志保存在当前浏览器的 localStorage，可导出 TXT 备份。
- 不需要服务器、API Key 或外部 JavaScript 库。

注意：这是玩家自制挑战页面，与 Electronic Arts / The Sims 无官方关联。示例世界名单需按自己拥有的游戏内容调整。
